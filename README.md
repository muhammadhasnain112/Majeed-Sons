# RubberTech Industries

Professional static website for a rubber and foam manufacturing / trading company.

Built with **HTML5, CSS3 and vanilla JavaScript only** — no React, Next.js, Bootstrap, Tailwind or jQuery.

## Company name

Search and replace `RubberTech` / `RUBBERTECH` / `rubbertech.com` to rebrand.

## Local preview

```bash
npx serve .
```

Then open the printed local URL (typically `http://localhost:3000`).

## Pages

| File | Page |
| --- | --- |
| `index.html` | Home |
| `products.html` | Products + category filter + detail modal |
| `about.html` | About Us |
| `industries.html` | Industries / Applications |
| `quality.html` | Quality & Manufacturing |
| `contact.html` | Contact + inquiry form |

## Image placeholders

Replace files in `images/` while keeping the same filenames:

- `images/logo.png`
- `images/hero.jpg`
- `images/products/*.jpg`
- `images/industries/*.jpg`
